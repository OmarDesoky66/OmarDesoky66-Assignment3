# CSharpBasicsAssignment

A C# console application covering the fundamentals from Lecture 01, including:

* Project structure
* Variables, types & casting
* Value vs. reference types
* Stack & heap memory
* Scope & operators
* Bitwise operations
* LeetCode 136 — Single Number using XOR

## Technologies

* C#
* .NET

## Project Structure

```text
CSharpBasicsAssignment/
├── CSharpBasicsAssignment.csproj
├── Program.cs
├── Order.cs
├── STACK_HEAP.md
├── ANSWERS.md
└── README.md
```

## Run

```bash
dotnet run
```

Each part is displayed with a clear console header when the program runs.
